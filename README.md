## Sistema de Gestão de Academia

Projeto desenvolvido como entrega do Assessment(AT) do Projeto de Bloco do 2º Semestre do curso de Análise e Desenvolvimento de Sistemas (ADS) no Instituto InfNet.

## Sobre o Projeto
O **Sistema de Gestão de Academia** é uma aplicação desenvolvida em C# que visa estruturar a arquitetura base e as regras de negócio essenciais para o gerenciamento de uma academia. A solução abrange o domínio de modelagem para o controlo de alunos, gestão de treinos e rotinas operacionais, servindo como modelo estruturado para a evolução contínua do software.

## Funcionalidades Principais:
- Cadastro e gestão de alunos e professores.
- Registo de fichas de treino e exercícios.
- Controle e acompanhamento de matrículas.
- Estruturação das regras de negócio operacionais da academia.

## Utilizado:
- **Linguagem:** C#(.NET)
- **IDE:** Visual Studio
- **Controlo de Versões:** Git & GitHub
